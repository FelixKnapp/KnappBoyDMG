# Gameboy Emulator 
- written in C++
- without any use of AI in code writing
- External libraries: 
    - [json.hpp by nlohman](https://github.com/nlohmann/json)
    - [tabulate.hpp by p-ranav](https://github.com/p-ranav/tabulate)
- has a comman line tool called gb which features opcode viewing debug tools and much more
